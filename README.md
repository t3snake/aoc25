## Advent of Code 2025

Solving Advent of Code 2025 series using C++ only using C features with some C++ added sugar. 

To run this in visual studio:  
- Open folder and choose the cloned project.
- cd into the respective day.
- Use command `cl -Zi <filename.cpp>` to compile with debug information.
- Right click generated exe file in `Solution Explorer` view and choose `Set as Startup Item`.
- Run `F5` or click on play icon to launch debugging mode
